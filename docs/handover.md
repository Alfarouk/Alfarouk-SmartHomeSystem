1. Turn on the bedroom lamp with a text command.
2. Set the main light to 30 percent.
3. Run movie time and explain the three state changes.
4. Show that a negated or misspelled command does not operate a device.
5. Try to open the locked door, then explain the refusal, code check and
   automatic close in the simulator.
6. Run the tests and explain how a failed scene leaves the home unchanged.

Then describe your own academic contribution in your own words. Separate the
parts you designed, coded, integrated, tested or coordinated from teammates'
work and from this later AI-assisted restoration. Do not memorize claims about
modules you have not personally reviewed.

- How did the team divide work and track dependencies?
- What actually ran on the Raspberry Pi and Arduino?
- What serial protocol and wiring did the team use?
- Where is the original facial module, and what did it test?
- Which failure took the most time to find?
- What would you change before using this with real hardware?

Keep the current simulator as the dependable laptop demo. Original hardware
photos, team contribution notes, wiring and firmware can later extend the
evidence. Add them with their real provenance; do not substitute a newly written
adapter for proof of the historical build.
