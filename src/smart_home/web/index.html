WHAT THIS DEMO SHOWS

One controller.
Several ways to use it.

The text assistant, device controls and scenes share the same validated state machine. An unclear command makes no change. A failed scene leaves every device as it was.

Device and room controls, text commands and scenes use one controller. Optional voice, face comparison and serial tools run separately, keeping the dashboard lightweight and local.

Voice, face and hardware limits

Optional offline voice input and consented-image face comparison run separately from this dashboard. The dashboard controls simulated devices. Physical GPIO and Arduino integration require a hardware adapter and tested firmware. Face comparison does not unlock doors. No live hardware or microphone is accessed here.
